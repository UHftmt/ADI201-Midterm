# Baseline versus Pilot (ADI501 only, 3 points)

First write your **pilot question** (one sentence naming the decision a manager would make with your tool; Idea 5 students copy it from their proposal). Then pick **one** measure. State the unit and the scale. Label every number *measured* or *estimate* and say how you got it.

| Field | Your entry | Example |
|---|---|---|
| Pilot question | | *Should the salon pilot online booking for haircuts only?* |
| Measure and unit | | *Minutes to book every request in the file* |
| Scale (what inputs) | | *All the requests in `booking-requests.csv`* |
| Baseline (how it is done today) | | *34 minutes (measured: I booked them by hand in a spreadsheet and timed myself)* |
| Pilot (your tool, same inputs) | | *6 minutes (measured: pasted the 20 requests into the tool)* |
| Difference | | *28 minutes less, about 82% faster* |
| What this does not prove | | *One person, one sitting; the spreadsheet user knew the data; real bookings are messier.* |

If the baseline is only an estimate, say why you could not measure it.
